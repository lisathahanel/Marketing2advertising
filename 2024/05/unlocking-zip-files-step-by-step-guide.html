Step 3: Crack the Hash


Now, it's time to crack the hash using John the Ripper. Run the following command in the terminal:

John the Ripper will start cracking the password. Depending on the complexity of the password, this process can take some time. Once John the Ripper has cracked the password, it will display it on the screen.
