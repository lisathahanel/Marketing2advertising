# Marketing2Advertising Mobile

The official Marketing2Advertising mobile application, built with Flutter for Android and iOS from one shared Dart codebase.

## Implemented foundation

- Branded M2A home screen and five-tab navigation.
- Native Blogger article list with search, refresh, and links to full articles.
- Native TV channel directory loaded from the existing `assets/channels.json`, with search and category filters.
- HLS video playback for listed TV streams, with graceful handling when a broadcaster's stream is unavailable.
- Firimu and Series open within the app using the existing M2A entertainment website.
- Discover, Services and More entry points.
- Existing channel, app, game and page catalogues retained under `assets/`.

The app is being developed incrementally. The Games, Jobs, saved-content/profile, notifications and offline features are not yet complete. A catalogue entry is not a guarantee that a third-party stream is live or that every region can access it.

## Project structure

```
flutter_project/
  android/                 # Android manifest and Flutter runner generated by CI
  ios/                     # iOS runner generated by CI on macOS
  assets/                  # Existing M2A catalogues
  lib/
    features/
      blogs/                # Blogger feed screen
      tv/                   # Channel directory and stream player
    shared/                 # In-app web content viewer
    main.dart               # App entry point and navigation
  test/                     # Widget tests
  pubspec.yaml
```

## Requirements

- Flutter stable with Dart 3.3 or later.
- Android Studio / Android SDK for Android builds.
- macOS with Xcode for iOS builds. Flutter's iOS toolchain requires Xcode on macOS: https://docs.flutter.dev/platform-integration/ios/setup

## Android development

```bash
cd flutter_project
flutter doctor
flutter create --platforms=android --org com.marketing2advertising --project-name marketing2advertising_mobile .
flutter pub get
flutter analyze
flutter test
flutter run
flutter build apk --debug
```

Build a release APK or Play Store App Bundle only after signing and store configuration are ready:

```bash
flutter build apk --release
flutter build appbundle --release
```

Do not commit keystores, passwords, signing properties or service-account credentials.

## iOS development

On a Mac with Xcode installed:

```bash
cd flutter_project
flutter create --platforms=ios --org com.marketing2advertising --project-name marketing2advertising_mobile .
flutter pub get
flutter build ios --no-codesign
```

The CI workflow generates the iOS runner on macOS for unsigned simulator build validation. App Store/TestFlight distribution requires Apple signing and provisioning; see https://docs.flutter.dev/deployment/ios.

## Content sources and safeguards

- Blog content: https://www.marketing2advertising.com/
- Entertainment application: https://marketing2advertising.com/
- TV channel entries are loaded from the existing JSON catalogue. Stream uptime, regional access and usage rights must be verified before promoting a channel as operational.
- Blogger articles are retrieved from the public Blogger JSON feed. If the feed is disabled or unavailable, the screen provides a retry and website fallback.
- The unused Google Mobile Ads / AdMob SDK has been removed. No native ad SDK is currently initialized. Existing website advertising can render in the in-app web content; any future mobile ad integration needs a separately reviewed consent, privacy and policy implementation.
- Push notifications, offline sync, saved content, native Games and Jobs screens, user profile and production monetization remain future integrations.
- Do not scrape or duplicate content unnecessarily. Prefer supported feeds or APIs and respect source-site terms.
